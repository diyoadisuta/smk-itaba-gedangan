# Website Profil Resmi SMK ITABA (Gedangan, Sidoarjo)

Website profil resmi **SMK Islam Tarbiyatul Badriyah (SMK ITABA) Gedangan, Sidoarjo** (NPSN: `69852106`), di bawah naungan Yayasan Al Badriyah Al Mustofa.

---

## 🌟 Fitur & Struktur Halaman

Website ini dirancang dengan arsitektur multi-halaman (*multi-page*), modern, cepat, dan responsif:

1. **Beranda (`index.html`)**: Ringkasan profil sekolah, keunggulan kejuruan, sorotan fasilitas & ekskul, pesan kepala sekolah, teaser Instagram resmi, dan informasi SPMB.
2. **Profil Sekolah (`profil.html`)**: Identitas resmi, visi & misi, nilai budaya santri & pembiasaan pagi (Sholat Dhuha, Yasin & Tahlil), 14 sarana & prasarana lengkap (Gedung 3 Lantai terakreditasi), serta 15 ekstrakurikuler & komunitas belajar.
3. **Program Keahlian (`program.html`)**:
   - **Desain Komunikasi Visual (DKV)**: Desain grafis, multimedia, studio foto & podcast, animasi 2D/3D.
   - **Teknik Kendaraan Ringan Otomotif (TKR)**: Pemeliharaan mesin, kelistrikan otomotif, chasis, dan budaya industri K3.
   - **Program Khusus Magang & Kerja ke Jepang** bekerja sama dengan LPK Hamaren & PT. Nippon Aqua.
4. **Pustaka Galeri & Instagram (`galeri.html`)**: Feed visual terintegrasi dengan akun resmi `@smkitabagedangan`, bar sorotan cerita (*Story Highlights*), tab filter kategori dokumentasi, dan alat semat postingan Instagram langsung.
5. **Sambutan & Pendidik (`sambutan.html`)**: Pesan resmi Kepala Sekolah (Dr. Joko Siswanto, M.Pd.I) beserta seluruh jajaran dewan guru dan tenaga kependidikan.
6. **Informasi Kontak (`kontak.html`)**: Alamat lengkap, kontak WhatsApp, email resmi, peta lokasi interaktif Google Maps, dan tautan seluruh media sosial sekolah.
7. **SPMB Online 2027/2028 (`spmb.html`)**: Jadwal gelombang pendaftaran, rincian biaya transparan, 5 stel seragam gratis, persyaratan, dan tautan formulir Google Forms online.

---

## 💻 Teknologi yang Digunakan

- **HTML5 Semantik**: Struktur dokumen ramah SEO dan aksesibilitas (*screen reader accessible*).
- **Vanilla CSS3**: Sistem desain responsif, tipografi modern (*Plus Jakarta Sans* & *Fraunces*), variabel CSS, dan animasi *scroll-reveal*.
- **Vanilla JavaScript**: Navigasi mobile responsif, filter dinamis kategori galeri, *intersection observer*, dan integrasi Instagram.

## 🚀 Menjalankan Secara Lokal

Cukup jalankan server lokal sederhana menggunakan Python atau ekstensi Live Server:

```bash
# Menggunakan Python HTTP Server
python -m http.server 5500
```

Buka peramban di `http://localhost:5500`.
